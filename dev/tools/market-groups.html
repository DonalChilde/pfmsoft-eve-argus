Up to 10 details are fetched concurrently, without time-based rate limiting or automatic retries. A failed request stops the download; no partial dataset is exported.

The selected language applies to the next fetch; the current dataset and its save filename retain the language used to fetch it.

Dataset

The receipt time is from the last completed response; expiry is from the ID-list response. ESI requests do not form an atomic snapshot. ESI type lists may differ from static data exports. Fields unavailable from ESI, including icon_id and has_types, are omitted.

Market paths

Market groups form a hierarchy. Each path starts at a root group and follows its parent-child chain to the group itself. int_path contains the group IDs; str_path contains the corresponding names returned by ESI in the same order. For example, an illustrative child might have int_path: [4, 9] and str_path: ["Ships", "Frigates"].

A root group's path contains only itself and its parent_group_id is null. For other groups, parent_group_id identifies the immediate parent. types contains the type IDs returned by ESI for that group, not an aggregation of its descendants.
