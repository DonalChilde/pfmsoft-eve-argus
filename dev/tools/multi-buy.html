EVE multi-buy helper

Import and inspect material lists. Data stays in this page's memory until you close or reload it.

Volume and Est. Price calculations are approximate. EVE uses three decimal places internally, but inventory exports display only two with rounding. Per-unit values inferred from these rounded stack totals, and later totals and exports, may differ from the game. Results display two decimal places; extra calculation digits do not restore the missing precision.

Import

Preserve existing per-unit Volume and Est. Price when importing. New items still receive metadata; quantities and descriptive fields still update. Applies when Parse is selected.

Accepts ten-column inventory or two-column Name / Quantity Markdown tables, tab-delimited inventory, or Name / Quantity in either order separated by tabs or spaces. Markdown cell whitespace is trimmed. Quantities must be non-negative integers; commas are supported and a dash (-) means zero. Zero-quantity rows are ignored and do not update metadata. Blank lines, recognized headers, and Markdown delimiter rows are ignored.
