EVE multi-buy helper

Import and inspect material lists. Data stays in this page's memory until you close or reload it.

Import

Accepts ten-column, tab-delimited inventory rows, or Name / Quantity in either order, separated by tabs or spaces. Quantities must be non-negative integers; commas are supported and a dash (-) means zero. Blank lines and recognized column headers are ignored.

Import not applied. Previous data is unchanged.
