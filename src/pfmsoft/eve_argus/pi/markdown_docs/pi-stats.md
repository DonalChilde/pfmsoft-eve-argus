### PI Link Cost

- Minimum Link Distance = .012008578 x radius of planet in km.
- pg cost of link = 10+(.15 x length)
- cpu cost of link = 15+(.2 x length)
- Links cost -.26 PWG per km, and -.36 CPU per km.
- 20 PWG and 28 CPU given as examples of link cost on a 4870 km radius planet.

## Import Export Cost

The formulas for importing and exporting materials

- Exporting via launchpad - `Base cost * tax rate`
- Importing via launchpad - `Base cost * tax rate * .5`
- Export via CC - `Base cost * tax rate * 1.5`
- Importing via CC - Not Possible

Low and Null sec Player-Owned Customs Offices (POCOs) have a tax rate set by the owner.

High sec POCOs have an NPC rate of 10%, plus the owner rate. The NPC rate can be offset by up to 5% via the Customs Code Expertise skill.

## Producing PI

PI material production is divided between mining planets, and factory planets, with a bit of mixing in some situations.
This split is due to the PG and CPU limits of the available Command Centers.

P0 materials are mined on planets, and typically refined in place to P1 materials due to export/import costs.

Some planets support producing both inputs to a P2 material, and this is often done to produce those P2 materials at a lower cost than using a factory planet.

Some P2, and all P3 and P4 production takes place on factory planets

### PI Categories

P3 and P4 materials can be categorized based on complexity of inputs.

- P3-Complex - P3 that consists of 3 different P2 inputs, or 6 P1 inputs
- P3-Simple - P3 that constists of 2 different P2 inputs, or 4 P1 inputs.
- P4-Low - P4 that consist of 2 P3-Simple inputs, and a P1
- P4-Medium - P4 that consist of 3 P3-Simple inputs
- P4-High - P4 that consist of 3 P3-Complex inputs
